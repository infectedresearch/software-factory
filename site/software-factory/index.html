Software Factory
Technical Report

Software development with an unattended agent loop.

Infected Research / FrackLabs Preliminary field study

Download the paper ↓Read full HTML report ↗Get source & data ↓
The result in one sentence

Fourteen agents produced 132 commits over roughly 4.5 hours; 110 factory commits survived review and initial integration, with zero new test failures relative to an already-failing baseline.

Generation was the easy part.

We ran parallel coding loops on a private production application, each assigned a narrow area. Every commit went through an automated gate and model review. A blind sample was re-reviewed, high-risk changes received operator sign-off, and the accepted work was integrated and deployed.

The original keep rate was 30% for the broad loop and 89% for scoped lanes. The prompts and gate also changed, so this is an observational comparison—not proof that scoping alone caused the difference.

What the numbers mean

  • 848 million tokens, including repeated cached context. Approximately $493 at the recorded list prices, across the collected writing, review and supervision snapshot.
  • 77 non-minor bug-fix commits and approximately 98 engineer-hours are AI estimates. They are not independently measured savings.
  • 181 baseline Python failures, 174 candidate failures, zero new failures. All 1,123 Node tests passed. “Green” means regression-relative, not a failure-free Python suite.
  • 11 of 12 blind keep decisions agreed. A small sample, with model reviewers rather than an independent human audit.

What review caught—and what we corrected later

The review rejected low-value changes and required fixes to promising ones. Publication review then exposed a second distinction: tests that documented a defect were not the same as a deployed fix. Seven filter findings were remediated, and a held tips-recipient defect received an indexed fix. Both follow-ups are deployed and recorded separately from the initial-release totals.

Inspect the artifacts

The bundle includes the factory loop, gate, review prompts, synthetic tests, report builders, five vector figures, token accounting, pass timings, review dispositions, AI value labels and blind spot-check results. The factory code is MIT-licensed; original research and data are CC BY 4.0.

The target application is private. Application code, patches, raw transcripts, credentials and Git history are excluded. Public metadata is sanitized; sensitive records are category-only. You can reproduce the arithmetic and exercise the gate on synthetic repositories, but cannot independently rerun the private application’s evaluation.

Limitations worth keeping attached

One night, one application, no human control group, and no randomized comparison. Workflow permissions were command-pattern controls, not an OS sandbox. Token prices and usage are a frozen snapshot; later remediation and publication work are outside it. The report is preliminary and not peer-reviewed.
