# Publication scope

This is a fresh-history, allowlisted export from the factory tooling repository.

Included: orchestration source, gate/reviewer logic, synthetic factory tests, prompts, report
generation, original research assets, sanitized numerical metadata and license notices.

Excluded: private application source and patches, private Git history, databases, runtime state,
lane environment files, service configurations, logs, credentials, raw agent transcripts,
private review packets and unresolved exploit details.

The harness retains references to example application paths in test selectors and prompts.
These references do not include application files. Host-local absolute paths are placeholders.
The snapshot is published for inspection and adaptation, with operational limitations documented.

Initial-release figures remain frozen. Later fixes appear in `research/followup.json` and the
paper's remediation section. `MANIFEST.sha256` records the bytes in the publication release.
